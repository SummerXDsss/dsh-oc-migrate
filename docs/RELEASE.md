# 0.5.1 · 标题与项目名称识别

- 读取 DSH 工作区注册表中的正式名称，以及 OpenCode 1.x/2.x 原生项目自定义名；不再仅取路径末段。源端没有标题时，扫描列表明确区分首条消息提示与空白对话，不把 ID 当作标题。
- 保留一键迁移全部对话，新增「先扫描，再选择」路径；DSH / OpenCode 两个方向均可扫描后按项目或对话勾选迁移。
- 新增项目与对话管理器：项目树、关键词搜索、收藏筛选、本地显示名称、对话预览及分页。预览包含中文正文、思考、工具参数/结果和被替换的历史标记。
- 扫描不执行导入；管理信息独立保存在本机，不重命名源工具历史或移动项目文件。选择迁移绑定扫描 ID、源内容 SHA-256 与已识别的 OpenCode 版本；源变化或旧扫描失效时要求重新扫描，不悄悄扩展为全量迁移。
- 已接入原有备份、原生回读、取消、幂等和原目标回滚；扫描异常逐条呈现，不把坏记录加入可选列表。
- 新增真实 OpenCode 1.18.31 / 2.3.2 双向选择迁移回归，以及管理器过滤、分页、转义和元数据持久化测试。

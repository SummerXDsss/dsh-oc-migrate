# 项目与对话管理器（0.5）

## 先扫描，再迁移

1. 工作台选择 **DSH → OpenCode** 或 **OpenCode → DSH**，点击 **指定对话导入**。本机位置默认自动发现；高级自定义位置会用于这次扫描。
2. 管理器显示真实项目数、对话数和扫描异常。此时尚未导入。左栏按项目绝对路径分组；存在的目录解析符号链接，原始路径仍保留。同名但不同路径的目录不会合并；中栏支持标题、源 ID、路径和本地名称搜索。
3. 点击一条对话预览正文、思考、工具记录；DSH 被压缩/替换的消息会明确标记。列表每页 40 条、预览每页 20 条；过长单条预览显示前 12,000 字并提示，迁移原件不因此截断。
4. 单条勾选，或选择项目后点击 **选择当前结果**，再点击 **迁移已选 N 个对话**。当前结果包含符合筛选的全部分页，不只是屏幕上的 40 条；跨项目选择会保留，底栏显示总数，可随时清空。
5. 只处理明确勾选的源条目，运行进度和结果进入原来的迁移工作台/记录；停止、重试和回滚沿用原有机制。扫描后新出现的对话不会混入这次迁移。

## 本地管理

- 项目和对话可以保存本地显示名称；留空恢复源名称。对话可收藏/取消收藏，支持只看收藏。
- 名称与收藏跨重开、重新扫描保留，不改源工具标题、项目目录或会话内容；也不作为迁移后的原生标题。
- 此版不删除源对话、不移动仓库文件，不是两个产品之间的实时同步。
- 工作台与管理器顶部均可切换 **DSH → OpenCode / OpenCode → DSH**；管理器切换后自动扫描新来源，清空旧勾选与预览。记住上次方向，运行中锁定；自定义位置跨方向保留，「重新扫描」沿用当前扫描位置。

## 一致性与存储

扫描清单保存在应用数据目录的 `catalog-latest.json`，本地名称/收藏保存在 `catalog-metadata.json`。清单记录扫描 ID、项目、源内容 SHA-256、来源和目标版本，不把预览全文常驻清单。目录与文件沿用应用私有权限。

预览会重新读取原件并核对指纹；迁移前再核对选中项和目标版本。源变化会逐条报告「请重新扫描」，其余选中项继续；旧扫描或未知 ID、空选、重复选不启动迁移。重新扫描会清空勾选，避免沿用过期选择。导入依然先备份原件、严格格式校验与原生回读，不执行历史工具。

## 名称从哪里来

- 对话优先读取源端持久化标题（DSH 最新 `session/title` / OpenCode `info.title`）。无标题但有用户文字时，列表使用首条消息提示并明确标注；真正空白记录显示「空白对话」，ID 仍保留在预览。提示只用于浏览，不会悄悄写回源端或作为原生重命名操作。
- DSH 项目正式名称读取 sessions 同级 `storages/workspace.json` 的 v2 注册表；OpenCode 读取原生项目 API（2.x）或只读项目表（1.x）。工作区注册关系、根目录和自定义名称独立于源会话 cwd；迁移仍保留原会话 cwd。元数据缺失时按目录回退，损坏时显示提示，历史仍可扫描。

## 0.5.3：迁移名称，而不只是显示名称

- 默认保留源 cwd。DSH 正式工作区名写入 OpenCode 原生项目；反向把 OpenCode 项目名登记到 DSH 工作区 v2，成员包含迁入的会话。标题和正文都必须原生回读一致。
- **迁入 DSH 项目前先退出 DSH，完成后重新打开。** DSH 在运行时缓存并持有工作区，应用会拒绝与其同时写注册表。打开过且已产生写入/锁的会话仍沿用原有回滚保护。
- 目标已有不同的自定义项目名时不覆盖，任务明确报告冲突，可回滚本任务创建的历史后处理名称。OpenCode 全局项目保留其全局名称；源项目名仍在原件中。原目录不存在时，DSH 日志仍可导入，项目名/cwd 保存在原件，任务详情提示暂未分组。
- 插件高级连接或手动指定目标目录会合并到该目录。一个批次含多个不同项目名时，不用其中某个名字覆盖整个目标项目；每个源名称保存在原始迁移包。需要逐项目保留名称时，使用默认本机扫描/选择迁移路径。
- 项目/对话管理器中的「本地显示名称」仅是管理别名，不替代原生名称，也不回写源工具。扫描后原生项目名变化需要重扫。
- 旧导入记录仅在正文一致、目标标题仍是 ID 默认名称时自动修复。自定义标题不自动覆盖。回滚恢复旧标题并保留原有会话；迁入前自有项目名及用户后续改名均有保护。

DSH 首次冷列表使用独立投影缓存；0.5.3 迁入时一并生成只含标题的原生 v7 派生缓存，标题事实仍来自 session/title 日志。回滚仅移除本任务写入且未被后续改动的缓存。

## 指定某一条或几条对话

- **按标题选择**：搜索标题/项目并勾选，点击「迁移已选 N 个对话」。
- **按源 ID 选择**：展开「按对话 ID 指定导入」，粘贴一个或多个源 ID（换行、中英文逗号或分号分隔），点击「匹配并选中」。精确匹配后替换原有勾选，不自动导入；重复 ID 去重。未知 ID 或同 ID 多个原件会整组报错，原勾选保持不动。
- **只导入预览这一条**：打开对话，点击「仅导入此对话 → 目标工具」。这个按钮仅提交当前条，不连带其他勾选；直接开始导入，进度返回工作台。
- 方向切换后的扫描失败时，不展示旧来源的可导入列表；重新扫描成功后再选择。指定导入和一键全量是独立入口，不会因空选、无匹配或扫描失败降级为全量迁移。
